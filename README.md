# 🍁 Maple Discord Application Bot

메이플랜드 파티 지원 및 디스코드 자동 역할 부여/닉네임 변경 시스템입니다.

## 🛠️ 주요 기능
- **웹 지원서 제출**: 웹페이지를 통해 유저가 인게임 정보 및 직업을 간편하게 제출
- **디스코드 자동 연동**: 제출 즉시 디스코드 봇이 유저에게 역할(손님/용병 등) 부여 및 닉네임 형식 자동 변경 (`[역할] [직업] 닉네임`)
- **서버리스/클라우드 운영**: 24시간 안정적인 구동을 위한 백엔드 연동

## 📂 프로젝트 구조
- `index.html`: 지원서 작성 웹 인터페이스 (GitHub Pages 배포용)
- `bot.py`: 디스코드 봇 및 API 처리 핵심 파이썬 스크립트
- `Dockerfile` / 설정 파일: 클라우드 배포용 세팅

## ⚙️ 환경 변수 설정 (.env)
로컬 테스트 또는 서버 배포 시 아래의 환경 변수 설정이 필요합니다.
- `DISCORD_TOKEN`: 디스코드 봇 토큰
- `GUILD_ID`: 대상 디스코드 서버 ID
